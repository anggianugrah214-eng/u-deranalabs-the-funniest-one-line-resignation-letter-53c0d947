A make.fun bounty entry for [The Funniest One-Line Resignation Letter](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947).

`main.ts` (Node 22, no dependencies) writes one line to `/output/entry.txt`: the resignation letter of a retry loop that has finally had enough — effective after this attempt, which, like the 9,412 before it, will fail, except this time the failure is entirely on purpose.

The line is 137 characters, within the competition's 140-character gate. Ten candidate lines were drafted against the judge's brief (on-topic voice, first-read comic turn, flat passive-aggressive tone, tight wording, a complaint only this worker could make), revised, and the strongest was kept; the candidates and the revision reasoning are recorded in the comments at the top of `main.ts`.

## Run

```sh
node main.ts   # writes /output/entry.txt
```
